# CryptoHacks

 Python-based collection of cryptography challenges and problem-solving scripts.

 ## Overview
 This repository contains solutions and learning notes from cryptography exercises focusing on classical cyphers, modular arithmetic, and key-based encryption.

 ## Tools & Languages
 - Python3
 - Libraries: `pycryptodome`, `base64`, `hashlib`

 ## Features
 - Cipher decryption and encryption algorithms  
 - Hashing and encoding utilities  
 - Modular arithmetic and XOR challenge scripts

 ## What I learned
 - Implementing and understanding symmetric/asymmetric encryption  
 - Bitwise operations and encoding  
 - Practical cryptography through problem-solving
